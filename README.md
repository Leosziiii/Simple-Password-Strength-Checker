# Password Strength Checker

A simple password strength checker made with C++. It checks password length and character types to determine whether a password is **Weak, Medium, or Strong**.

## Features

* Checks password length (at least 8 characters)
* Checks uppercase and lowercase letters
* Checks numbers and special characters
* Allows users to check multiple passwords

## Built With
* C++

## Purpose
A beginner project to practice C++ programming.
